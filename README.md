# WAVE RACE — ทริปน้ำไม่อาบ

เกมแต่งและซิ่ง Honda Wave ทางตรง ¼ ไมล์ (0.402 กม.) เขียนด้วย HTML + Canvas + JavaScript ล้วน
ไม่มี dependency ไม่ต้อง build เป็น static site ที่ deploy ขึ้น Vercel ได้ทันที

## Deploy บน Vercel

**วิธี A — CLI**
```bash
npm i -g vercel
cd wave-race
vercel          # ตอบ Enter ตามค่าเริ่มต้น (Framework: Other, ไม่ต้องมี build command)
vercel --prod
```

**วิธี B — GitHub**
1. push โฟลเดอร์นี้ขึ้น GitHub
2. vercel.com → Add New → Project → เลือก repo → Deploy (ไม่ต้องตั้งค่าอะไร)

**ลองรันในเครื่อง**
```bash
npx serve .     # หรือ python3 -m http.server 8000
```

## เปิดกระดานอันดับออนไลน์ (ไม่บังคับ)
เกมเล่นได้เต็มระบบโดยไม่ต้องตั้งค่าอะไร (อันดับในเครื่อง + ลีกบอท 15 ตัว) ถ้าอยากได้กระดานออนไลน์:
1. Vercel → Project → Storage / Marketplace → เพิ่ม **Upstash Redis**
2. ตัวแปร `UPSTASH_REDIS_REST_URL` และ `UPSTASH_REDIS_REST_TOKEN` (หรือ `KV_REST_API_URL`/`KV_REST_API_TOKEN`) จะถูกใส่ให้เอง → Redeploy
3. ในเกม: แท็บ 🏆 อันดับ → ใส่ชื่อ → ติ๊ก "ส่งสถิติขึ้นกระดานออนไลน์"

ข้อควรรู้: เวลาแข่งคำนวณในเบราว์เซอร์ ฝั่งเซิร์ฟเวอร์ตรวจแค่ความสมเหตุสมผล (ET ≥ 9 วิ ฯลฯ) จึงกันโกงไม่ได้ 100%

## วิธีเล่น
- **รุ่นรถ**: Honda Wave (4T) เริ่มต้น → ซื้อ LS125 / Kawasaki Serpico / KR150 (2T) ด้วยเงินจากการแข่ง
  2T แรงต่อซีซีสูง ช่วงกำลังแคบ ต้องคุมรอบ และลูกสูบตายง่ายถ้าใส้ในไม่พอ
- **โรงรถ**: เลือกอะไหล่ในแท็บ เครื่องยนต์ / ส่งกำลัง / ช่วงล่าง — ชี้เมาส์ (หรือแตะ) เพื่อ *ลองใส่* ดูบนตัวรถก่อนซื้อ
  (โช้ค YSS/Showa/Öhlins, เบรก Nissin/J.Costa/Brembo, ท่อแชมเบอร์ 2T, คลัตช์, ข้อเหวี่ยง ฯลฯ)
- **โรงกลึง Craft**: กลึง ลูกสูบ / ก้านสูบ / ข้อเหวี่ยง / แคม(ลิ้นรีด) / ท่อไอเสีย ได้สเปก `Q/G` เช่น `95/9`
  - `Q` = คุณภาพงานกลึง (%) , `G` = เกรดวัสดุ 1–9
  - อลูมิเนียม G1–3 • เหล็กกล้า G3–6 • ไทเทเนียม G6–9 (มีโอกาสชิ้นงานร้าวสูงขึ้นตามวัสดุ)
  - ขัดละเอียด = Q ขั้นต่ำ 88%
- **แข่ง**: ค้าง `Space` เร่งเครื่องให้เข็มอยู่โซนเขียว → ปล่อยตัวตอนไฟเขียว → `↑`/`Shift` เปลี่ยนเกียร์ตอนเข็มชนโซนแดง → `N` ใช้ NOS
  - มือถือมีแถบปุ่ม GAS / เกียร์ / NOS แยกใต้ฉาก (แนวนอนเป็นปุ่มลอยมุมขวา)
  - ฉากหลังสุ่ม 6 แบบ (หรือเลือกเองในแท็บตั้งค่า) • โหมดง่าย = เกียร์ออโต้
- **อันดับ**: ลีกบอท 15 ตัว เรียงตาม ET จริง + สถิติส่วนตัว Top 15 + ชื่อตำแหน่ง
- เซฟอัตโนมัติใน localStorage + ส่งออก/นำเข้าไฟล์เซฟได้

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `data.js` | รุ่นรถ / แคตตาล็อกอะไหล่ / สูตรสถิติ / Craft / บอท 15 ตัว |
| `sim.js` | ฟิสิกส์ ¼ ไมล์ (แรงบิด, เกียร์, กริป, แรงต้านลม, NOS) |
| `bike.js` | วาดรถทุกรุ่นตามอะไหล่ + ภาพตัดเครื่อง + กราฟ dyno |
| `scenes.js` | ฉากหลัง 6 แบบ |
| `race.js` | โหมดแข่ง HUD เสียง ผลแข่ง |
| `main.js` | โรงรถ UI ร้านอะไหล่ รุ่นรถ Craft อันดับ เซฟ |
| `api/leaderboard.js` | Serverless function กระดานออนไลน์ (Upstash Redis) |

ปรับบาลานซ์ได้ที่ `data.js` (ค่า `pw`, `dur`, `kpc`, `price` และรายชื่อ `BOTS`)

> เกมสมมติเพื่อความบันเทิง — สเปกทั้งหมดเป็นค่าสมมติ ชื่อยี่ห้อใช้เพื่ออ้างอิงบรรยากาศเท่านั้น ห้ามซิ่งบนถนนจริง สวมหมวกกันน็อกเสมอ
