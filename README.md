# WAVE RACE — ทริปน้ำไม่อาบ

เกมแต่งและซิ่ง Honda Wave ทางตรง ¼ ไมล์ (0.402 กม.) เขียนด้วย HTML + Canvas + JavaScript ล้วน
ไม่มี dependency ไม่ต้อง build เป็น static site ที่ deploy ขึ้น Vercel ได้ทันที

## Deploy บน Vercel

**วิธี A — CLI**
```bash
npm i -g vercel
cd wave-race
vercel          # ตอบ Enter ตามค่าเริ่มต้น (Framework: Other, ไม่ต้องมี build command)
vercel --prod
```

**วิธี B — GitHub**
1. push โฟลเดอร์นี้ขึ้น GitHub
2. vercel.com → Add New → Project → เลือก repo → Deploy (ไม่ต้องตั้งค่าอะไร)

**ลองรันในเครื่อง**
```bash
npx serve .     # หรือ python3 -m http.server 8000
```

## วิธีเล่น
- **โรงรถ**: เลือกอะไหล่ในแท็บ เครื่องยนต์ / ส่งกำลัง / ช่วงล่าง — เอาเมาส์ชี้ (หรือแตะ) เพื่อ *ลองใส่* ดูบนตัวรถก่อนซื้อ
  พร้อมดูผลต่างของแรงม้า, ET, ความเสี่ยงเครื่องพัง
- **โรงกลึง Craft**: กลึงลูกสูบ/ก้านสูบด้วยวัตถุดิบ ได้สเปก `Q/G` เช่น `95/9`
  - `Q` = คุณภาพงานกลึง (%) , `G` = เกรดวัสดุ 1–9
  - อลูมิเนียม G1–3 • เหล็กกล้า G3–6 • ไทเทเนียม G6–9 (มีโอกาสชิ้นงานร้าวสูงขึ้นตามวัสดุ)
  - ขัดละเอียด = Q ขั้นต่ำ 88%
- **แข่ง**: ค้าง `Space` เร่งเครื่องให้เข็มอยู่โซนเขียว → ปล่อยตัวตอนไฟเขียว → `↑`/`Shift` เปลี่ยนเกียร์ตอนเข็มชนโซนแดง → `N` ใช้ NOS
  - มือถือมีปุ่ม GAS / เกียร์ / NOS บนจอ
  - เปิด "โหมดง่าย" ได้ (เกียร์ออโต้)
- ภายในเครื่องทนไม่พอกับแรงม้า = เสี่ยงเครื่องพังกลางทาง → ต้อง Craft ใส้ในดีๆ
- เซฟอัตโนมัติใน localStorage

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `data.js` | แคตตาล็อกอะไหล่ / สูตรคำนวณสถิติ / ระบบ Craft / คู่แข่ง |
| `sim.js` | ฟิสิกส์ ¼ ไมล์ (แรงบิด, เกียร์, กริป, แรงต้านลม, NOS) |
| `bike.js` | วาดรถ Wave ตามอะไหล่ที่ติดตั้ง + ภาพตัดเครื่อง + กราฟ dyno |
| `race.js` | โหมดแข่ง ฉาก HUD เสียง ผลแข่ง |
| `main.js` | โรงรถ UI ร้านอะไหล่ Craft เซฟ |

ปรับบาลานซ์ได้ที่ `data.js` (ค่า `pw`, `dur`, `mu`, `final` ฯลฯ) และ `OPPONENTS`

> เกมสมมติเพื่อความบันเทิง — ห้ามซิ่งบนถนนจริง สวมหมวกกันน็อกเสมอ
